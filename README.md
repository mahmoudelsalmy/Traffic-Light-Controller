# 🚦 Traffic Light Controller (VHDL)

A **Simple 4-Way Traffic Light Controller** implemented in **VHDL** using a **Finite State Machine (FSM)** architecture.  
The project is designed for simulation using **Xilinx ISE + ISim**.

---

## 📌 Project Overview

This system controls a standard 4-way intersection traffic light with the following fixed sequence:

1. **North/South Green**
2. **North/South Yellow**
3. **East/West Green**
4. **East/West Yellow**
5. Repeat...

Each state has a fixed duration:
- **Green = 5 seconds**
- **Yellow = 2 seconds**

A single **Start/Stop push button** is used to enable or disable the whole system.

---

## 🧠 Design Architecture (Modular Design)

The project is divided into 3 required VHDL modules:

### ✅ 1) FSM Controller Module
- Controls the traffic light states.
- Implements a Moore FSM.
- Generates the outputs:
  - `NS_green`, `NS_yellow`, `NS_red`
  - `EW_green`, `EW_yellow`, `EW_red`

### ✅ 2) Timer Module
- Takes the input clock (configured as **1 kHz**) and generates a **1 Hz tick pulse**
- The FSM uses this tick to count seconds.

### ✅ 3) Input Control Module
- Handles the Start/Stop button logic.
- Includes debouncing logic.
- Generates:
  - `enableAll` → Enables the FSM + Timer
  - `resetAll` → Resets the FSM + Timer
- Drives an LED indicator showing system status.

## ▶️ Simulation Instructions (Xilinx ISE + ISim)

### 1) Create the project
- Open **Xilinx ISE**
- Create new project
- Select:
  - Family: Spartan3E
  - Device: XC3S100E
  - Package: VQ100
  - Speed: -5
  - Preferred Language: VHDL

### 2) Add Source Files
Add these design files:
- `top_level.vhd`
- `fsm_controller.vhd`
- `timer.vhd`
- `inputControl.vhd`

### 3) Add Testbench
Add:
- `top_level_tb.vhd`

### 4) Set Top Module
In the left panel:
- Right click `top_level.vhd` → **Set as Top Module**
- Right click `top_level_tb.vhd` → **Set as Top Module (for simulation)**

### 5) Run Simulation
- Select **Simulate Behavioral Model**
- Open waveforms
- Observe traffic light outputs changing in time.

## ✅ Expected Simulation Output

Once the Start signal is activated, the outputs should cycle like this:

### North/South Direction
- `NS_green` stays HIGH for **5 seconds**
- then `NS_yellow` HIGH for **2 seconds**
- then `NS_red` HIGH while EW is active

### East/West Direction
- `EW_green` stays HIGH for **5 seconds**
- then `EW_yellow` HIGH for **2 seconds**
- then `EW_red` HIGH while NS is active

---

## 🧪 Verification (Testbench)

The testbench validates:
- Reset behavior
- Start/Stop behavior
- Correct state transitions
- Correct timing:
  - Green = 5s
  - Yellow = 2s
- Correct mutual exclusion:
  - NS and EW can’t be green at the same time

---

## 📌 Notes

- This project is designed for simulation only.
- The timer is configured for a **1kHz input clock**.
- Timing is based on **1Hz tick pulses** generated by the timer module.
- The Start button is handled as a toggle:
  - Press once → system ON
  - Press again → system OFF
