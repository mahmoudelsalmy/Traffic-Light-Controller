# Traffic Light Controller (VHDL)

## 📌 Description
This project implements a **Traffic Light Controller** using **VHDL**.
The design is based on a **Finite State Machine (FSM)** to control traffic
lights for multiple directions.

---

## 🧠 Design Overview
- FSM-based controller
- Synchronous design
- Modular VHDL components
- Separate testbenches for verification

---

## 📂 Project Files
- `fsm_controller.vhd` : FSM logic
- `top_level.vhd` : Top-level module
- `timer.vhd` : Timing control
- `inputControl.vhd` : Input handling
- `*_tbw.vhd` : Testbench files

---

## 🛠️ Tools
- VHDL
- Xilinx ISE / Vivado
- ISim / ModelSim (for simulation)

---

## ▶️ How to Simulate
1. Open the project in your VHDL tool
2. Compile all source files
3. Run the testbench files
4. Observe waveform results
